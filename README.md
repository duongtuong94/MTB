# BIM Test

Bộ công cụ pyRevit cho Autodesk Revit. Runtime hiện được phát triển cho Windows,
Revit 2025 và IronPython 2.7.

Repository này chứa bản phân phối: `BIM Test.tab/`, `lib/`, `extension.json` và
hướng dẫn cập nhật. Clone bằng Git, sau đó cấu hình pyRevit nạp thư mục extension
theo cách cài extension trên máy. Đảm bảo đang nạp đúng checkout.

```powershell
git clone https://github.com/duongtuong94/MTB.git
```

Nút **Update Tools** nhận bản stable theo tag `vMAJOR.MINOR.PATCH`. Push main
không tự tạo bản phát hành. Xem [UPDATING.md](UPDATING.md).

Một số thao tác ghi dữ liệu vào model; đọc tooltip và kiểm tra trên bản sao
phù hợp trước khi áp dụng vào công việc. Tooltip button có tiếng Việt/English.
